## 2.4 决策矩阵

以下帮助根据团队情况选择工具：

### 场景 A：刚接触 Agent 编码，快速建立规范化流程

```
推荐: Superpowers
原因: 
  · 最成熟的全流程方法论（14 项技能覆盖完整生命周期）
  · Anthropic 官方支持
  · 学习资源丰富（中文社区也有大量资料）
  · 实践证明可减少中大型功能 50%+ 开发时间
```

### 场景 B：已有流程，需要加严质量门禁和评审

```
推荐: Superpowers + agent-harness-kit 叠加
原因:
  · Superpowers 提供流程骨架
  · agent-harness-kit 补充 10 维度的深度评审、SQLite 追踪、成本管控
  · 两者互补不冲突
```

### 场景 C：频繁启动新项目，快速搭建 Agent 环境

```
推荐: HarnessForge → 再叠加 Superpowers
原因:
  · HarnessForge 3 秒生成 AGENTS.md/MEMORY.md 等全套配置文件
  · 在此基础上安装 Superpowers 获得完整流程
  · 避免每次手动搭环境
```

### 场景 D：需要极致安全合规

```
推荐: agent-harness-kit + Harness Skills
原因:
  · agent-harness-kit 的 9 组 Hook 覆盖全生命周期安全拦截
  · Harness Skills 的 CI/CD 治理能力
  · 金融场景可启用 harness-forge 的 no_trades_without_gate 安全扫描
```

## 2.5 趋势分析

### 2026 年 Harness Engineering 的关键趋势

```yaml
趋势 1: 从 Prompt 约束走向机械强制
- 软约束（"请遵守规范"）→ 硬约束（运行时守卫、状态机、断路器）
- 代表: agent-harness-kit 的 Hook 系统、OpenHarness 的验证合同

趋势 2: 多运行时统一
- 一个配置跑遍 Claude Code / Codex / Cursor / GitHub Copilot
- 代表: Superpowers 的跨平台支持、HarnessFlow 的多 IDE 兼容

趋势 3: 极速初始化
- "3 秒搭好 Agent 环境"成为标配
- 代表: HarnessForge、harness-init

趋势 4: 可观测性深度集成
- 从 CLI 日志 → SQLite/OTel → 可视化 Dashboard
- 代表: agent-harness-kit 的 SQLite 追踪、OpenTelemetry 集成

趋势 5: MCP 协议成为标准接口
- MCP 成为 Agent 工具的标准协议
- 代表: Harness Skills MCP v2、各工具的 MCP Server 模式
```
