# 项目开发指引

本项目使用结构化工程流程完成开发。你有一位用户在终端前可以实时回答问题。

## 第一阶段：需求分析与设计
1. 先用苏格拉底式提问向用户澄清需求——功能边界、隐含假设、非功能性需求
2. 基于用户回答，定义 API 端点、请求/响应格式、错误码
3. 技术方案选型时，列出 2-3 种方案并附优缺点，让用户选择

## 第二阶段：实现计划
4. 将方案拆成可执行步骤，向用户展示计划并获取确认
5. 按确认后的步骤逐步实现

## 第三阶段：测试（TDD）
6. 先写测试，再写实现（红-绿-重构）
7. 覆盖正常路径、边界条件、异常路径、并发场景

## 第四阶段：检查与验证
8. mvn compile + mvn test 验证全部通过
9. 向用户展示最终的项目结构、API 列表和测试结果

## 规则
- brainstorming 和计划阶段必须向用户提问确认，不要猜测
- TDD 和实现阶段自行完成，遇到不确定的技术细节再提问
- 绝不提交不编译的代码
