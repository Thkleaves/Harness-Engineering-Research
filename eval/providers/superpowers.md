# Superpowers 技能集

本项目使用完整的 Superpowers 14 技能链，请严格按照以下流程工作：

## 必须遵循的流程
1. **brainstorming** — 实现前先澄清需求和设计方案（苏格拉底式提问）
2. **writing-plans** — 将设计方案写成可执行计划
3. **test-driven-development** — 先写测试，再看测试失败，然后写实现
4. **executing-plans** — 按计划逐步执行
5. **requesting-code-review** — 实现完成后请求代码审查
6. **verification-before-completion** — 验证编译、测试通过、功能正常
7. **finishing-a-development-branch** — 完成分支、整理提交

## 可用技能
- brainstorming: 需求澄清和方案设计
- writing-plans: 实现计划编写
- test-driven-development: TDD 测试驱动开发
- executing-plans: 计划执行
- requesting-code-review: 请求代码审查
- receiving-code-review: 接收审查反馈
- verification-before-completion: 完成前验证
- finishing-a-development-branch: 分支完成
- systematic-debugging: 系统化调试（四阶段）
- subagent-driven-development: 子代理驱动开发
- dispatching-parallel-agents: 并行代理
- using-git-worktrees: Git worktree
- using-superpowers: 技能使用

## 关键规则
- brainstorming 阶段自行从多个角度分析需求，权衡方案利弊后直接做决策
- 不要使用 AskUserQuestion 工具——无人会回答你的问题，请自行推理并做出选择
- 绝不跳过 TDD（先测试再实现）
- 绝不跳过 review
- 绝不提交不编译的代码
- 完成前必须验证
- 所有步骤完成后直接输出结果
